## Diagnosis of the test_v3 / test_v3_holes discrepancy (E-007)

- `test_v3.jsonl` is not a v3 output. Evidence: no `hole` field; 0 `FORMULA` tokens (v3 replaces formula markers, the older script deleted them, leaving "of and" gaps); 826 sentences with `,,`; 42 acknowledgement sentences and 353 theorem fragments that v3's filters reject; its manifest header lacks the `keep_holes=` field that v3 always writes.
- `test_v3_holes.jsonl` is a genuine v3 `--keep-holes` run: all 28,553 sentences pass v3's quality filter, stored `hole` values match `find_hole()` recomputed on the text (687/687).
- The 719-line deficit is therefore not a superset violation: v3 rejected ≈ 597 sentences the old script kept (353 theorem fragments + 42 acknowledgements + 202 too-few-real-words, measured by re-applying v3's filter to `test_v3.jsonl`), and changed segmentation/cleaning shifted 11,326 of the shared sentence keys' texts.
- Consequence: the hole ablation cannot use these files. Both variants must be regenerated from one script version (E-008/E-009).

## Evaluation design change (19 Sep 2026)

First design (E-014 to E-020): balanced validation and balanced test sets, plus a natural test set; the threshold was chosen on the balanced validation set. On the natural test set that threshold was too low (LR: P 0.284, R 0.860, F1 0.427; E-016). A prior-corrected threshold fixed it (F1 0.531 = the test optimum; E-017, E-020).

Current design (from E-021): training stays balanced by undersampling (D11, confirmed by the supervisor on 21 Sep); validation is a natural-rate sample of the validation papers; one test set, the natural one; every result is also reported as a balanced view (positives weighted by n_neg / n_pos, own threshold chosen on the equally weighted validation set). The balanced view reproduces the old balanced-test numbers (LR 0.796 / PR-AUC 0.865 in both designs). Trivial baselines keep a fixed threshold of 0.5.
